SHAHEEN MD BOT - HOSTING NOTE

InfinityFree shared hosting cannot run the Node.js WhatsApp Baileys process itself.
Use a Node.js-capable host (VPS, Render, Railway, Koyeb, etc.) for the bot.
InfinityFree can host the optional PHP/static landing page only.

START:
1. Upload this ZIP to a Node.js host.
2. npm install
3. Copy .env.example to .env and add your own credentials.
4. npm start
5. Open the public URL and use the pairing flow.

IMPORTANT SECURITY:
The original source contained exposed Telegram/Groq credentials. They were removed from this package.
Create/rotate your own credentials and put them in .env.
Do not upload .env to GitHub.

PM2:
pm install -g pm2
pm run pm2
